# Пакет Calculator

Модульный калькулятор на Python для выполнения базовых арифметических операций (+, -, *, /).

## Структура пакета
- `calculator_pkg/` — исходные модули пакета и файл инициализации `__init__.py`.
- `tests/` — модульные тесты.

## Пример использования
```python
from calculator_pkg import calculate

print(calculate(10, "+", 5))  # Выведет: 15
